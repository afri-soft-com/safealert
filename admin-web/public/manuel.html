SafeAlert — Guide citoyen (application mobile)

SafeAlert est l’application de sécurité citoyenne d’AfriSoft : alerte SOS, contacts de confiance, carte des incidents et entraide de quartier.

Dernière mise à jour : 5 septembre 2026

1. Connexion

  1. Saisissez votre numéro (ex. 0812… — l’indicatif +243 est ajouté si besoin).
  2. Appuyez sur « Envoyer le code » et consultez le SMS.
  3. Saisissez les 6 chiffres. Première utilisation : cochez « Nouveau compte » et choisissez un pseudo.
  4. Créez un code PIN local pour les prochaines ouvertures (plus de SMS à chaque fois).

2. Alerte SOS

  • Depuis l’accueil, ouvrez le bouton rouge SOS, puis maintenez environ 2 secondes.
  • Votre position est envoyée ; vos contacts de confiance sont alertés.
  • Annulation : « Fausse alerte — annuler » dans les minutes suivant l’envoi.
  • SOS discret (Android) : 3× Volume bas avec l’app ouverte, ou secouer le téléphone.

3. Autres fonctions

  • Contacts de confiance — proches alertés par SMS et notification.
  • Carte — incidents à proximité ; mode invité possible sans compte.
  • Groupes voisins — entraide de quartier (électricité, inondation, rue bloquée…).
  • Trajet sécurisé — partagez un code pour qu’un proche suive votre trajet.
  • Mises à jour — une bannière peut apparaître pendant l’usage si une nouvelle version est disponible.

4. Où trouver ce guide dans l’app

Accueil → Aide / Manuel, ou Paramètres → Aide / Manuel d’utilisation.

5. Console d’administration

Réservée aux administrateurs plateforme. Après connexion, le menu Aide décrit les pages de la console.
