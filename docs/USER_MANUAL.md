### Recent UX (EN)

- **Danger / Vigilance / Safe** map chips are tappable filters.
- **Heatmap** is hidden by default (server feature flag).
- Place names come from GPS + OpenStreetMap; fallbacks: « Position approximative » / « Lieu en cours de résolution », always with coordinates when available.
- With GPS off, SafeAlert uses the last known position when possible.
- SOS and incident views show **place name + coordinates**; WhatsApp/share and SMS include them.
- Neighbour groups, discreet (calculator) mode, and neighbourhood watch are covered in the French manual.
